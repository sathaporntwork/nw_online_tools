TARGET LAUNCHER

พิมพ์ target ครั้งเดียว เปิดได้ทุกเครื่องมือ

กรอก domain / IP / ASN แล้วการ์ดเครื่องมือที่รองรับ deep-link จะแสดงปุ่ม “เปิดพร้อม target” ให้ ไม่ต้องพิมพ์ซ้ำในแต่ละเว็บ

ยังไม่ได้กรอก target — เมื่อกรอกแล้วจะมีปุ่มเปิดเครื่องมือพร้อมค่าอัตโนมัติ

SYMPTOM-BASED TRIAGE
